{# TableRow — Bundle A primitive #3 (Task 123, FE-MED-002) First sibling-list-slot primitive. Wraps a row of one or more `` siblings with consistent hover + selection + clickable states. Different shape from Card: Card body is one contiguous block (works with `{% call %}` + `caller()`); TableRow body is N sibling `` cells (does NOT fit `{% call %}` naturally without forcing callers to wrap cells in an opaque blob). Slot pattern: open/close pair, NOT call/caller. {% from "primitives/table_row.html" import tr_open, tr_close %} {{ tr_open() }} ... ... {{ tr_close() }} Why open/close not {% call %}: - body is naturally a sibling list (), not one contiguous block. Wrapping cells in caller() loses the per-cell structure. - Existing per-table markup is already `......`. Open/close lets callers adopt the primitive incrementally without restructuring cells. - Adds structural hooks (hover/selection state classes) without reinventing cell typography. Existing classes (.td-symbol, .td-ts, .td-sub, .td-dim, .mono) keep working unchanged. Parameters: state "default" (just .tr-p base) or "clickable" (adds .tr-p-clickable — cursor:pointer + stronger hover). Future states: "selected" via separate selected flag (below). on_click optional JS expression for onclick attribute. When set, also implies state="clickable" if not overridden — eliminates the redundant pair at call sites. id optional DOM id (for JS targeting). Empty omits. extra_class optional space-separated class names appended to the wrapper. For ad-hoc states the primitive doesn't directly model (e.g., backfill-pending rows that need a specific border). Empty omits. States composed via class: .tr-p base — provides hover background on default rows. .tr-p-clickable stronger hover + cursor:pointer. .tr-p-selected selected-state background. Toggle via JS classList (no separate macro param — selection is dynamic, not initial).
